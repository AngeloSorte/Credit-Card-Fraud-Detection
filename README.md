# Payment Security AI Model

This project uses a Machine Learning model to detect suspicious transactions and prevent credit card payment fraud.

## 📂 Included Files
- `notebook.ipynb` → Notebook with the code for training the model.
- `credit_card_fraud_model.pkl` → Saved model ready to be used.
- `README.md` → This file, with the project description.

## 🚀 Technologies Used
- Python, Scikit-Learn, Pandas, Matplotlib
- Dataset: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
